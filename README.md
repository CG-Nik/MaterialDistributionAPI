# MaterialDistributionAPI
This mod serves as an API mod and patch mod that adds a Distribution to the Wyrm, Crystal Wyrm, Thin Cloth Medium Square, and Rope Clump. This allows other mods to add materials that can be naturally spawned from these sources.  
This mod needs to be on both the Client and Server.  
Requires https://github.com/CG-Nik/CustomDistributionAPI on both the Client and Server.  

Devs making mods that depend on this mod should make sure their priority is above -100, or else the Distributions may not be created by the time they try to access them.  

This is an unofficial, fan-made mod for A Township Tale. This mod is not affiliated with or endorsed by the owners or developers of A Township Tale.
